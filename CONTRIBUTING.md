# Contributing to vauban-verify

Thank you for your interest. This package is the offline cryptographic verifier for Vauban Command Center proof certificates.

## Issues
Open an issue at https://github.com/vauban-org/vauban-verify/issues for:
- Bugs in verification logic
- Cross-language Poseidon vector mismatches
- Documentation gaps

## Pull Requests
- Fork → branch → tests pass (`pytest tests/`) → PR
- Maintainers will review and merge if aligned with the project goals
- All contributions are licensed under MIT (see LICENSE)

## Code of Conduct
Be respectful. Disagree with substance, not personalities.

## Security
Vulnerabilities: email security@vauban.tech (do not open public issues).
